# 🚗 PatentePlay

### Your personal space to study for the Italian Driving Licence (Patente B)

PatentePlay is a lightweight, browser-based study dashboard designed to help learners organize and track their preparation for the Italian driving licence theory exam.

The project brings together learning videos, study chapters, personal notes, and progress tracking in one simple interface.


---

## ✨ Features

- **📚 25 Study Chapters** — Organized theory topics covering the Italian driving licence syllabus.
- **🎥 Video Library** — YouTube lessons grouped by their corresponding chapters.
- **✅ Progress Tracking** — Mark individual videos as completed and monitor your study progress.
- **🔎 Search & Filter** — Quickly find chapters and filter between completed and unfinished topics.
- **📝 Personal Notes** — Write and automatically save your study notes in your browser.
- **📄 PDF Catalogue** — Keep track of important PDF resources identified from the study group.
- **💾 Backup & Restore** — Export your progress as a JSON file and import it later.
- **📱 Responsive Design** — Study from desktop, tablet, or mobile.
- **⚡ Lightweight** — No frameworks, database, or installation required.

## 🚀 Getting Started

You can use PatentePlay directly through its hosted website or run it locally.

### Option 1 — Use the Website

Visit the live website and start studying. No account or installation is required.

### Option 2 — Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/patenteplay.git
   ```

2. Open the project folder:

   ```bash
   cd patenteplay
   ```

3. Open `index.html` in your browser.

That's it! The application runs directly in your browser.

---

## 🌍 Deploy with GitHub Pages

PatentePlay is a static website, so it can be hosted for free using GitHub Pages.

1. Open your GitHub repository.
2. Navigate to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose `Deploy from a branch`.
5. Select the `main` branch.
6. Select the `/(root)` folder.
7. Click **Save**.

GitHub will automatically publish your website.

Your website URL will look like:

```text
https://YOUR-USERNAME.github.io/patenteplay/
```

## 💾 Data & Privacy

PatentePlay uses your browser's Local Storage to save:

- Completed videos
- Personal study notes

Your study data stays in your browser and is not uploaded to a server.

**Important:** Local Storage is device- and browser-specific. Your progress will not automatically synchronize between devices.

Use the built-in **Export Backup** and **Import Backup** features to transfer your progress.

---

## 📌 Project Limitations

- The PDF catalogue contains filenames identified from the original study-group chat. The original PDF documents are not included.
- YouTube videos require an internet connection.
- Study progress is stored locally rather than in a cloud database.
- An internet connection is required to access the hosted website and external video resources.
